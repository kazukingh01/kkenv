# 目的

"./DESIGN.md" を作成し、中身を完成させよ. "DESIGN.md" はアプリケーションの設計書として機能する事を目指す

# 方法

1. @./DESIGN.md が存在しない場合は、作成する
2. 以下の「TEMPLATE」の内容をコピーする
3. 「設計書雛形」にある指示に沿って、"./DESIGN.md" を編集する
4. ```git diff ./DESIGN.md``` を実行し、以下について判断し編集せよ
  - 新規に追加された項目は、今回のものを優先する
  - 削除された項目は、削除したままで良い
  - あなたが編集した個所では無い、雛形の文言が明らかに変更になっている場合は、今回のものを優先する
  - コンフリクトした項目や内容は、現在の「設計書雛形」に照らし合わせた上で、以下をさらに判断する
    - 意味的な違いはなく、言葉のみ差異がある場合、前回のものを優先する（git commit による差分をキレイにするため）
    - 但し、追加されたファイルやディレクトリ構造の違いがある可能性もあるので、その点は注意して今回のものを優先すべきかどうか判断する
    - 現在の「設計書雛形」指針から外れる記述がある場合、今回のものを優先する

# 設計書雛形

- ```template``` で囲まれた以下の内容が **TEMPLATE** (雛形)である
- あなたが編集する箇所は <<< 指示内容. 例）XXXX >>> といった形で、"<<<" と ">>>" で囲んだ箇所である。その中の指示内容に従って編集せよ. 例がある場合は、それに沿った形で編集せよ
- それ以外の箇所はそのままコピーし、編集してはならない
