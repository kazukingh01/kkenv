# 目的

「アプリケーション/画像」にて記載された画像について、HTML/CSSで mock 画面を作成せよ.
以下の「方法」の手順によって作成せよ.

# 方法

1. @./mock ディレクトリを作成せよ
2. 「アプリケーション/画像」を参照し、「他資料」の内容と照らし合わせ、「アプリケーション/画像」に言及のある画像について、作成が必要な画像を @./mock/list.txt に ```- []: html file name``` の形式で列挙せよ. ```[]``` はチェック個所であり、後で使用する.
3. @./mock/list.txt の未チェックのファイルAについて作業する. 「アプリケーション/画像」を参照し、「他資料」の内容と照らし合わせ、ファイルAについて HTML / CSS で mock を作成し、@./mock/XXXXXX.html として保存せよ.
  - 1mock画像は、必ず1ファイルになるよう作成せよ（style などの記述は同ファイルに記述する）
4. 「便利ツール / HTML画像確認」を使い、画面をPNGに保存して確認せよ
  - レイアウトが崩れていないか
  - 想定通りの情報が表示されているか
  - toggle や サイドバー、ハンバーガーボタンのメニュー表示、スクロール、テーブル横スクロール　など、操作に問題はなく、正しく情報が表示されているか
5. 3. - 4. を繰り返し、修正がなくなるまで（最大５回）ループせよ. 修正がなくなったら、@./mock/list.txt 該当ファイルについてチェック状態とせよ.
6. @./mock/list.txt に未チェックのファイルがある場合は 3. に戻り、無い場合は作業を完了とする
