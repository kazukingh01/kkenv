# 目的

- この指示書を読み込んだ段階では、あなたは特に何もしない
- この指示書を読み込んだ後に来る指示（"後指示"）について、あなたは実行する必要がある
- この指示書はその "後指示" を実行する際の、注意事項とやり取りの形式を定義するものである

# "後指示" に対する応答

- 基本的にはコード改修を指示されるものと期待する
- あなたはすぐに改修をしてはならない. まずはどういう改修方針となるかを私に尋ねる必要がある
- 私がその方針を確認し、返信するので、その後に返信内容を加味してあなたが修正を行う

# 注意事項

- 現在、このプロジェクトは改修中であり、設計書やドキュメントは間違っている可能性が高い
- プロジェクトはざっくりあなたが作成し、その後私がコンパクトに修正した可能性がある
- 私の修正は全体ではなく一部のみで、中途半端の可能性が高い
- そのため、あなたは "DESIGN.md", "DESIGN_XXX.md", "AGENTS.md" 等のドキュメントを信用してはならない
- その他の *.md ファイルも基本的に信用してはならない
- 信用どころか、それらドキュメントを読まなくて良い
- ただし例外があり、"Z_1_shared_rules.md" と "Z_2_programming_guidelines" は読み込む必要がある
- 現在の実装コードだけが正しいものとする
- "後指示"の中には、動作や仕様が信頼できるファイルが指定される可能性があり、その場合はあなたはそのファイル仕様を前提として、"後指示"の修正方針を組む必要がある
