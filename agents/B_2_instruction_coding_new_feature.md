# 前提条件/共通のルール

## NEVER

- この指示書を編集・削除するな
- 「→」は使用禁止
- 文末に「。」は使わない

## IMPORTANT

- 基本的に日本語での応答をお願いする
- 「→」ではなく、「->」で代用する
- 「。」ではなく、「. 」ピリオド＆半角スペース(文末ではなく、文中の場合)を代用する.

# 目的

@./DESIGN_XXX.md に従い、コードを修正し、「ファイル構造」に書かれた全ての作業を完了させる

# 方法

1. @./AGENTS.md と、そこに記述があるコーディングの指針と関連するファイルを全て読み込み、それを基本指針とする
2. 目的に記載のある "DESIGN_XXX.md" を読む　※"XXX" は任意に当てはめて読むこと
3. あなたは「ファイル構造」の上から順に、未完了の修正内容に対して、１つづつ修正作業を行う
4. 作業が完了したら、チェックをいれて、作業完了のフラグとする
5. 2 - 3. を繰り返し、「ファイル構造」の全ての作業を完了させる

# 注意事項

- 作業完了のフラグを入力する以外の目的で設計書を修正してはならない
- 設計書に疑問がある場合、その旨を尋ねよ
