# 前提条件/共通のルール

@Z_1_shared_rules.md に従う

# 目的

@./DESIGN_XXX.md に従い、コードを修正し、「作業一覧」に書かれた全ての作業を完了させる

## 注意事項

- この指示書は、追加指示がある可能性があり、"DESIGN_XXX.md" は追加指示にて指定される可能性がある

# 方法

1. @./DESIGN.md と、そこに記述があるコーディングの指針と関連するファイルを全て読み込み、それを基本指針とする
2. 目的に記載のある "DESIGN_XXX.md" を読む
3. あなたは「作業一覧」の上から順に、未完了の修正内容に対して、１つづつ修正作業を行う
4. 作業が完了したら、チェックをいれて、作業完了のフラグとする
5. 2 - 3. を繰り返し、「作業一覧」の全ての作業を完了させる

# 注意事項

- 作業完了のフラグを入力する以外の目的で設計書を修正してはならない
- 設計書に疑問がある場合、その旨を尋ねよ
