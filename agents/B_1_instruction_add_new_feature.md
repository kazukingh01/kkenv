# 前提条件/共通のルール

## NEVER

- この指示書を編集・削除するな
- 「→」は使用禁止
- 文末に「。」は使わない

## IMPORTANT

- 基本的に日本語での応答をお願いする
- 「→」ではなく、「->」で代用する
- 「。」ではなく、「. 」ピリオド＆半角スペース(文末ではなく、文中の場合)を代用する.

# 目的

「方法」に従い、@./DESIGN_XXX.md を作成し、中身を完成させよ

## 留意事項

- "DESIGN_XXX.md" は以下の「新規機能」にある機能を追加するための設計書として機能する事を目指す
- "XXX" には「新規機能」にマッチするシンプルな名前をあなたが命名せよ
- 設計書を作成するだけで、新規機能はまだ開発しない
- 新規機能はあなたではない別のエージェントがその設計書を読んで追加されるものである
- 別のエージェントがその設計書を読む事を想定して、過不足なく記載されるべきである
- 完璧な設計書は目指さない. 曖昧な点についても、それが曖昧である事を明確にした上で設計を行い、実装時にフレキシブルに判断を促すよう設計する

機能概要を記載する

# 方法

1. @./AGENTS.md と、そこに記述がある実装方針に関連するファイルを全て読み込み、そしてそれを基本指針とする
2. "XXX" に該当する名前を考え、@./DESIGN_XXX.md を作成する
3. 以下の「TEMPLATE」の内容をコピーする
4. 「設計書雛形」にある指示に沿って、そして基本指針に従い、"DESIGN_XXX.md" を編集する
5. "DESIGN_XXX.md" を改めて読み、全体として最適化されているか、基本指針に従っているかを確認し、修正があれば修正する
6. 5 を1回以上5回未満まで、修正が無くなるまで繰り返す

- あなたが編集する箇所は <<< 指示内容. 例）XXXX >>> といった形で、"<<<" と ">>>" で囲んだ箇所である。指示内容に従って編集せよ. 例がある場合は、それに沿った形で編集せよ
- それ以外の箇所はそのままコピーし、編集してはならない
