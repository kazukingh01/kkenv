# 前提条件/共通のルール

@Z_1_shared_rules.md に従う

# 目的

@./AGENTS.md を作成し、中身を完成させよ. その際、必ず @./DESIGN.md を読み込み、"DESIGN.md"をリファレンスする形で、"DESIGN.md" の記述以外を補完する形で、"AGENTS.md" を完成させよ


  - 役割と適用範囲: どのシナリオでどの指示書を使うかの一覧と意図
  - 参照先の明示: Z_1_shared_rules, Z_2_programming_guidelines, Z_3_application_image, Z_4_tools など必須参照のリンクと用途
  - 生成物とファイルパス: DESIGN.md / DESIGN_XXX.md / review.out / mock/*.html / DESIGN_database.md などタスク別に作るべき成果物と保存場所
  - 手順の骨子: 各タスクの大まかな流れ（読む -> 作る -> 確認する）と必須チェック（差分確認やチェックボックス運用など）
  - 命名規則とフォーマット: XXX の付け方、チェックボックスやナンバリング、カテゴリ例（BUG/STYLE/TEST/GRAYなど）
  - 禁則と注意事項: 「指示書は編集しない」「→禁止」「文末の 。禁止」など共有ルールの再掲
  - 不足情報時の対応: 前提が欠けたときに質問すべき内容や待機方針を一文で示す
# 方法

1. @./DESIGN.md を読み込む
2. @./AGENTS.md を作成する
