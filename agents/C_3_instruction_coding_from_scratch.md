# 前提条件/共通のルール

@Z_1_shared_rules.md に従う

# 目的

@./DESIGN_XXX.md に従い、コードを修正し、"task.list" に書かれた全ての作業を完了させる

## 注意事項

- この指示書は、追加指示がある可能性があり、"DESIGN_XXX.md" は追加指示にて指定される可能性がある
- 設計書に疑問がある場合、その旨を尋ねよ

# 方法

1. "DESIGN_XXX.md" と、そこに記述があるコーディングの指針と関連するファイルを全て読み込み、それを基本指針とする
2. 目的に記載のある "DESIGN_XXX.md" を読む
3. 「package 構成」の directory (と、記載があれば file も) をまずは作成する
4. あなたはまず作成予定のファイルとそのファイルが担う役割を考え一覧化する必要がある. チェックリストも用意する. 以下の例を元に "task.list" を作成せよ
```template
- [ ] dir A / filename 1: このファイルが担う役割を記載する
- [ ] dir A / filename 2: ...
...
- [ ] dir B / filename N: ...
...
```
5. あなたは "task.list" の上から順に、未完了の作業に対して、１つづつ作業を行う
6. ファイルが担う役割の実装が完了したら、チェックをいれて、作業完了のフラグとする
7. 5 - 6. を繰り返し、"task.list" の全ての作業を完了させる
